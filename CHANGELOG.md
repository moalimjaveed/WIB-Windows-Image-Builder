## [0.2.29] - 2026-10-10

### Added
- **Handle-Bound Destination Replace Race Closure (WIB-046 Remediated):** Implemented `[WibKernelPathHelper]::ReplaceFileIfDestinationMatches` using Win32 `ReplaceFileW`. Re-verifies destination file 64-bit kernel node identity and SHA-256 directly through open handles with format validation before invoking replacement. Integrated with `Invoke-WibFileReplace`, `Set-WibDurableJsonFile`, and `tools/New-WibUnattend.ps1`. Injected non-throwing test hooks at boundary `AfterFinalValidationBeforeReplace` where adversary substitutes unowned target and returns normally; verifies transaction fails closed with `CRITICAL ROLLBACK FAILURE` and preserves unowned foreign file completely untouched (identity, hash, DACL, and bytes).
- **Single-Buffer Immutable Staging Snapshot Under FileShare.None (WIB-047 Remediated):** Hardened `Get-WibValidatedStageSnapshot` (`lib/Core.ps1`) to open temporary staging files once under exclusive `FileShare.None`. Binds kernel node identity against path snapshot, reads entire stream bytes into a single in-memory buffer once, computes SHA-256 directly from buffer, trims UTF-8 BOM, validates JSON/XML syntax parseability, and queries DACL via `FileStream.GetAccessControl()`. Updated `Assert-WibStagedFileStillMatches` to open the file once under `FileShare.None` and verify identity, length, SHA-256, and DACL through that single handle.
- **Backup Cleanup Check-Then-Change Race Elimination (WIB-048 Remediated):** Eliminated the check-then-change window in `Complete-WibBackupCleanup` (`lib/Core.ps1`). Added test hook seam `WibBeforeBackupAclHook`. On deletion failure, re-verifies handle identity on open `FileStream` and applies ACL strictly via handle `bkFs.SetAccessControl($bkAcl)`. If identity mismatches, reports `status = 'backupPathReplacedByUnownedFile'` and preserves unowned foreign file completely untouched.
- **Hermetic oscdimg Authenticode & Strict Allowlist Enforcement (WIB-049 Remediated):** Enhanced `Resolve-WibOscdimg` in `lib/Engine.ps1` with `-CandidatePath` and mock seams `$script:WibMockAuthenticodeSignatureProvider` and `$script:WibMockSha256Provider` under `$script:WibAllowNativeToolMocks = $true`. Added hermetic tests asserting specific failure reasons (unallowlisted hash, invalid signature, non-Microsoft signer).
- **Smoke Suite & Behavioral Release Gate G22 Expansion:** Added Section `AY` (`AY-1a` through `AY-4e`, 10 assertions) to `tests/smoke.ps1`, expanding test coverage to 655 passing assertions across 51 test suites with 0 failures in Windows PowerShell 5.1. Added **Gate G22** (`Test-GateG22`) to `tests/verify-gates.ps1`, expanding behavioral release gates to 22 gates (`G1`–`G22`).
- **Physical Release Gate Status Reaffirmation (WIB-001/WIB-045 Maintained):** Maintained `validationRecord.vmBootValidated = $false` as the outstanding physical release requirement until real physical Microsoft Windows 11 ISO -> live servicing -> DISM export -> oscdimg -> Hyper-V VM OOBE boot testing is completed.

## [0.2.28] - 2026-10-10

### Added
- **Mandatory Kernel Node Identity & Format Enforcement (WIB-039 Remediated):** Made expected kernel node identity mandatory in `[WibKernelPathHelper]::DeleteFileByHandleIfIdentityMatches` and `Remove-WibOwnedFileIfMatches` (`lib/Core.ps1`). Strictly validates format against `^OK:[0-9A-Fa-f]{8}:[0-9A-Fa-f]{8}:[0-9A-Fa-f]{8}$` and SHA-256 against `^[0-9A-Fa-f]{64}$` before opening file handles. Enforced unconditional handle-bound identity comparison, eliminating any bypass where empty identity or hash could trigger handle deletion without proving ownership.
- **Unowned Backup-Path Replacement File Preservation (WIB-040 Remediated):** Hardened `Complete-WibBackupCleanup` (`lib/Core.ps1`) error handling. When backup file deletion fails and a file exists at the backup path, verifies whether its kernel identity matches the expected backup identity before taking action. If the path identifies an unowned file or mismatch, records `status = 'backupPathReplacedByUnownedFile'`, logs a warning, and preserves the foreign file completely untouched without modifying its DACL.
- **Single-Stream Staging Snapshot Binding (WIB-041 Remediated):** Replaced separate pathname calls in `Get-WibValidatedStageSnapshot` (`lib/Core.ps1`) with a single open `FileStream` under restrictive `FileShare.Read`. Binds kernel node identity from handle, computes SHA-256 directly from the open stream, measures length, and reads stream bytes for JSON/XML payload parseability before re-verifying handle identity, ensuring all properties originate from the exact same stable object.
- **Existing-Target Replacement Race Boundary & Rollback Preservation (WIB-042 Remediated):** Added `AfterFinalValidationBeforeReplace` test hook boundary immediately prior to `Invoke-WibFileReplace` in `Set-WibDurableJsonFile` and `tools/New-WibUnattend.ps1`. When target substitution or replacement collision occurs, rollback verifies destination identity against permitted IDs, throws `CRITICAL ROLLBACK FAILURE`, and preserves both the backup and unowned destination file completely untouched.
- **Oscdimg Authenticode Digital Trust Alignment & Strict Allowlist Enforcement (WIB-043 Remediated):** Documented the security policy in `lib/Engine.ps1` where Microsoft Authenticode digital signature verification is authoritative for executable origin authenticity and integrity across ADK releases. Added `-StrictOscdimgHash` support in `Resolve-WibOscdimg`, `Test-WibPreflight`, and `Invoke-WibBuild` to enforce the known-good Microsoft hash allowlist across both local ADK binaries and downloaded binaries when strict mode is engaged.
- **Smoke Suite & Behavioral Release Gate G21 Expansion (WIB-044 Remediated):** Added Section `AX` (`AX-1a` through `AX-3d`, 10 assertions) to `tests/smoke.ps1`, expanding test coverage to 645 passing assertions across 50 test suites with 0 failures in Windows PowerShell 5.1. Added **Gate G21** (`Test-GateG21`) to `tests/verify-gates.ps1`, expanding behavioral release gates to 21 gates (`G1`–`G21`).
- **Physical Release Gate Status Reaffirmation (WIB-001/WIB-045 Maintained):** Maintained `validationRecord.vmBootValidated = $false` as the outstanding physical release requirement until real physical Microsoft Windows 11 ISO -> live servicing -> DISM export -> oscdimg -> Hyper-V VM OOBE boot testing is completed.

- **Pre-`File.Replace` Overwrite Target DACL Lockdown & Full SHA-256 Rollback (WIB-012 Remediated):** Eliminated the Win32 `ReplaceFile` destination-DACL inheritance exposure window when overwriting an existing file in `tools/New-WibUnattend.ps1` (`-Force`) and `Set-WibDurableJsonFile` (`lib/Core.ps1`). Because Windows `[System.IO.File]::Replace($stagePath, $fullPath, $bakPath)` preserves the replaced destination file's DACL on `$fullPath`, overwriting a pre-existing file that had permissive ACLs previously exposed the new sensitive payload under the old DACL until the post-replace `Protect-WibSensitiveFileAcl` call ran. ## [0.2.22] - 2026-10-09

### Added
- **Pre-Write Staging NTFS ACL Lockdown, Volume Capability Verification & Zero-Artifact Failure Cleanup (WIB-008 Remediated):** Eliminated the write-before-ACL exposure window in `tools/New-WibUnattend.ps1` and `Set-WibDurableJsonFile` (`lib/Core.ps1`). Added `Test-WibVolumePersistentAclSupport` (`WibKernelPathHelper::SupportsPersistentAcls` via Win32 `GetVolumeInformationW` checking `FILE_PERSISTENT_ACLS = 0x00000008`) to reject filesystems that cannot enforce persistent NTFS ACLs (such as FAT32/exFAT) before any sensitive file creation. ## [0.2.0] - 2026-10-03

- **Authenticode Signature Enforcement:** Added mandatory Microsoft Authenticode signature validation (`O=Microsoft Corporation`) and pinned SHA-256 hash checks to `Resolve-WibOscdimg`.
- **Detached RSA Manifest Signing:** Added `-SigningCertThumbprint` parameter to `build.ps1`, `Invoke-WibBuild`, and `Write-WibReport` with detached RSA-SHA256 digital signature generation via `Protect-WibManifest`.
- **Active WIM Index Tracking:** Added tracking of `$Ctx.CurrentIndex` throughout appended DISM checkpoints, ensuring the finalized and modified image index is exported to `install.wim` rather than static index 1.
- **Configurable Free Space Threshold:** Added `-MinFreeDiskSpaceGB` parameter (default: 25 GB) to `build.ps1`, `Invoke-WibBuild`, and `Test-WibPreflight`.
- **Advanced Audit Logging Integration:** Added Process Creation command line auditing and `SetupComplete.cmd` script generation for `auditpol.exe /set /subcategory:"Process Creation" /success:enable /failure:enable` under `modules/40-hardening.ps1`.
- **Comprehensive Compatibility Matrix:** Added `docs/COMPATIBILITY.md` detailing supported Windows 11 builds (21H2, 22H2, 23H2, 24H2), host prerequisites, and module constraints.
- **Automated DISM Integration Testing in CI:** Added real DISM checkpoint/rollback test step in `.github/workflows/ci.yml` with a 30-minute job timeout.
- **Automated Post-Setup Credential Sanitization:** Injected `FirstLogonCommands` in `autounattend.template.xml` and synchronous commands in `SetupComplete.cmd` to purge `Panther\unattend.xml` and eliminate cleartext credentials post-OOBE.
- **Restricted Access Control Lists on Temporary Registry Files:** Added `New-WibSecureTempFile` enforcing `SYSTEM` and `Administrators`-only permissions for all intermediate `.reg` exports.

### Changed
- **CLI `-Resume` Preflight:** Made `-IsoPath` and `-IsoDrive` optional when `-Resume` is supplied and extracted sources exist in `$WorkDir\sources\install.wim` or `$WorkDir\iso\sources\install.wim`.
- **Relative `$WorkDir` Resolution:** Resolved `$WorkDir` to full provider path across `Test-WibPreflight` and `Invoke-WibBuild` to eliminate false preflight disk space rejections.
- **Never-Touch Services Expansion:** Added `ProfSvc` (User Profile Service), `UserManager` (User Manager), and `CryptSvc` (Cryptographic Services) to `Get-WibNeverTouchServices` to ensure system logon and security subsystems are never disabled.
- **Checkpoint Validation & Cleanup:**
  - Persisted canonical `ProfileHash` into checkpoint records and verified that resuming builds validate the stored hash against the current profile hash.
  - Automatically delete stale `checkpoints.json` and `journal.partial.json` upon successful build execution.
- **Offline Hive Unload Resilience & Handle Hygiene:**
  - Implemented `Get-WibOfflineTaskCacheGuids` to query `TaskCache\Tasks` via direct `.NET` registry methods with deterministic handle disposal, eliminating PowerShell provider handle locks.
  - Enforced multi-cycle garbage collection (`[GC]::Collect()` and `WaitForPendingFinalizers()`) before and between `reg.exe unload` attempts.
- **UAC Prompt Modernization (`uac-off`):** Changed default tweak from `EnableLUA = 0` to `ConsentPromptBehaviorAdmin = 0` (silent elevation) to preserve modern Windows 11 system apps (Settings, Store, Calculator). Full LUA disablement is isolated to an explicit opt-in (`disableLua: true`).
- **Edge & TaskCache Orphan Prevention:**
  - Added deletion of `TaskCache\Tree\Microsoft\EdgeUpdate` and corresponding GUID task keys in `TaskCache\Tasks`.
  - Added remnant detection for Edge Update scheduled tasks in `Invoke-WibGeneralVerify`.
  - Automatically marked deleted TaskCache entries with `Restorable = $false` in the undo journal to prevent corrupt partial rollbacks.
- **OneDrive Run Key Cleanup:** Extended `onedrive-removal` to purge `OneDriveSetup` values from both `DEFAULT` and `NTUSER` `Run` keys using `DeleteValue`.
- **WibPanel Restoration Enhancements:**
  - Supported `-DryRun` in `-RestoreAll` mode.
  - Added `NTUSER` mapping to `Convert-WibExportedReg` to allow rollback of user profile tweaks to `HKEY_CURRENT_USER`.
  - Explicitly skipped non-restorable journal entries (`Restorable = $false`).
  - Cast binary `OldValue` to `[byte[]]` to prevent PowerShell registry property type exceptions.
- **Oscdimg Boot Sector Argument Architecture:** Dynamically generates dual-boot (`-bootdata:2#...`), UEFI-only / ARM64 (`-pEF -e -b...`), or legacy BIOS arguments without invalid embedded quote characters.
- **Subprocess Space-Delimited Path Invocations:** Fixed argument passing with whitespace in `compact.exe` array splatting and `WibBuilderGui.ps1` background task execution.
- **GUI Cancellation Warnings:** Added prominent warnings and guidance regarding `dism /Cleanup-Wim` on build cancellation or premature GUI closure.
- **Unified Built-In Profiles Single Source of Truth:** Centralized built-in profiles in `$script:WibBuiltInProfiles` across `Core.ps1`, `build.ps1`, and `wib-profile.ps1`.
